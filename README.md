# 🔥 Firewall Academy X

A modern and interactive **Cybersecurity Learning Platform** designed to help students and beginners learn cybersecurity through structured courses, interactive lessons, practical activities, quizzes, firewall simulation, AI assistance, progress tracking, and verifiable certificates.

The system provides **50 different cybersecurity courses**, with each course containing unique, topic-specific educational content.

# 🔥 Firewall Builder

The **Firewall Builder** provides an interactive environment for learning and creating firewall rules.

### Rule Components

| Component | Purpose |
|---|---|
| Source | Defines traffic origin |
| Destination | Defines traffic target |
| Protocol | TCP, UDP, ICMP, etc. |
| Port | Defines service port |
| Action | Allow or Deny |
| Logging | Records firewall activity |
| Rule Generator | Generates firewall rules |
| Rule Explanation | Explains generated rules |

⚙️ Installation
Step 1 — Install Node.js

Download Node.js:

https://nodejs.org/

Check installation:

node --version
npm --version
Step 2 — Install MongoDB

Download MongoDB:

https://www.mongodb.com/

Default local connection:

mongodb://localhost:27017
Step 3 — Clone Repository
git clone https://github.com/YOUR-USERNAME/Firewall-Academy-X.git
Step 4 — Open Project
cd Firewall-Academy-X
Step 5 — Install Dependencies
npm install
Step 6 — Configure Environment

Create a .env file.

Example:

PORT=5000
MONGODB_URI=mongodb://localhost:27017/firewall_academy_x
AI_API_KEY=YOUR_API_KEY

Never upload real API keys or passwords to GitHub.

Step 7 — Start the Server
npm start

Or:

node server.js
🌐 Open the Website

Open Microsoft Edge or Google Chrome:

http://localhost:5000
