LAB GUIDANCE

How users should use the Cyber Lab

🔎

Port Detective

Learn common services such as SSH, HTTPS and RDP. Decide which services should be exposed and which should be restricted.

  1. Read the service and port.
  2. Choose the best answer.
  3. Review the explanation and earn XP.
📐

Rule Order Challenge

Understand why specific security decisions may need to take priority over broad rules depending on the firewall's evaluation model.

  1. Identify the broad rule.
  2. Find the narrow security decision.
  3. Think about evaluation order.
🔐

Least Privilege

Practice replacing broad policies with specific source, protocol and service combinations.

  1. Start with a broad example.
  2. Specify source and destination.
  3. Limit the protocol and port.
🧭

OWASP Mapping

Connect firewall and web-security thinking with the current OWASP Top 10:2025 awareness categories.

  1. Read the scenario.
  2. Select the matching category.
  3. Open the official OWASP resource for deeper study.
REWARDS

How points, badges & certificates work

⭐

XP & Points

XP measures progression toward levels. Points represent total learning activity across courses, labs, policy analysis and builder tasks.

Tip: Complete different activity types rather than repeating the same action.
🏆

Badges

Badges recognize milestones such as reaching XP thresholds, completing practical labs, saving firewall systems and generating code.

Tip: Open the Badges page to see earned and locked achievements.
📜

Certificates

Completing a course creates a course-specific certificate with learner name, certificate ID, issue date and XP information.

Tip: Use View Certificate, Verify, Share or Print / Save PDF.

Name your system

🛡️ Browser-safe firewall check

Your browser intentionally blocks websites from reading OS firewall configuration directly. This is a browser security restriction, not a website error. The check below therefore reports browser/network capabilities instead of falsely claiming that a firewall was detected.

Windows PowerShell 
Get-NetFirewallProfile
Linux 
sudo firewall-cmd --list-allufw statusnft list ruleset
